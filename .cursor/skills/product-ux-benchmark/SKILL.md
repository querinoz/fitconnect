# Product UX benchmark

Complete means: discover → understand → use → recover → result → next action.

Compare workflows with WHOOP, Oura, Garmin Connect, Strava, Apple Fitness, NRC/NTC. Adapt to `--eos-*` (floor `#070B14`, voltline `#C8FF00`).

Nav lock: Feed (social) → Ascend → TRAIN → Dashboard → Profile.

Insight → action examples: low recovery + shortened intensity + Accept / Keep / Why.

Required states: loading, empty, error, offline, permission, provider disconnected, rate limited. No fake telemetry.
