# Phase 06 — Metrics Engine

Schema from registry per sport. Custom metrics registerable at runtime (unlimited). Sample history stored locally.

Examples seeded: Running pace/cadence/VO2/GCT · Cycling FTP/power/NP/TSS · Swimming SWOLF/stroke/lap · Football sprints · CrossFit volume/rounds · Gym volume/sets/reps/1RM.

NP/TSS/GAP **formulas** remain in `elite-core` (ports later).
