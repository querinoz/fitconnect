# FitConnect — Squad spec

Squads are **not** implemented as an OS. Existing:

- ASCEND `ChallengeType.SQUAD` / `squad-fc-week` contribution km
- Home/Coach cards labeled LOCAL_DEMO
- Community `GroupKind.TEAM`

## Target (do not fake live members)

- Identity: name, mark, level from **sum of contribution**, not a new XP formula
- Live board: only real Wear/session packets (coach card already refuses to fake CONNECTED)
- Challenges: consistency, recovery week, team distance — **no zero-rest-day**
- Privacy: no GPS on the board without consent

## Navigation

Squad home is the first Community surface, not a sixth tab.
