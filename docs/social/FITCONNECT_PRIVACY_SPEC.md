# FitConnect — Privacy spec

## Defaults

| Data | Default |
| ---- | ------- |
| Location | OFF |
| HRV / sleep / medical | Never on public feed |
| Workout facts on posts | Opt-in `shareTelemetryFacts` |
| Coach location | `coachMayRead(LOCATION)` already |

## Visibility enum

PUBLIC · FOLLOWERS · CONNECTIONS · GROUP · COACH_ONLY · PRIVATE

## Granularity later

Friends / squad / coach / private for Prime. Do not ship public Prime on other athletes’ cards.
