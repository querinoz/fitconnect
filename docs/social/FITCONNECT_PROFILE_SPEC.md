# FitConnect — Profile spec (2.0)

Profile is a **player card**, not a form. Settings stay below the fold.

## Header (Phase C)

Avatar, display name, role, sports, equipped title (unlocked only), level, XP, streak, squad label (LOCAL_DEMO until Squad OS).

## Not Phase C

Banner upload, pinned posts, featured workout media, hover card on web, long-press sheet.

## Prime

Show readiness/Prime from existing `AthleteProfile` / home snapshot — never invent HRV on a public card. Public card may show level/title/sport; Prime only if the viewer is self or coach-assigned.

Phase C: Profile is **self** view — Prime/readiness from local repo is allowed with LOCAL_DEMO labeling where demo.
