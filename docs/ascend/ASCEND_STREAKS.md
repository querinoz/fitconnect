# ASCEND streaks

Kinds: PERFORMANCE, TRAINING, RECOVERY, SLEEP, GOAL, CONSISTENCY.

Calendar: UTC day = `timestamp / 86_400_000`.

**Streak protection:** a recovery day continues PERFORMANCE and CONSISTENCY as `RECOVERY_PROTECTED`. TRAINING does not increment on rest. A missed calendar day (gap > 1) sets `BROKEN`.

Copy must not use streak anxiety or “you failed”.
