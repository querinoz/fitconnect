# Phase 05 — Analytics Report

## Coach Analytics Center

`AnalyticsScreen` + `CoachRepository.analytics()`:

- Athlete evolution chart (`EliteChartKind.PERFORMANCE`)
- Recovery trends (`EliteChartKind.RECOVERY`)
- Attendance / program completion / retention / conversion
- Revenue cents
- Custom metrics map

## Revenue analytics

`RevenueScreen` via `CoachPaymentsGateway` — week/month/pending payout, subscriptions, bookings, invoices, transfers, payout rail status.
