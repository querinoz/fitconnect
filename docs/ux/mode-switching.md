# Mode switching UX

Profile → **ACTIVE EXPERIENCE**

- Show only owned capabilities.
- Athlete-only / Coach-only: no useless dual radio.
- Dual: radio cards Athlete / Coach.
- Missing Coach: “Unlock Coach Experience” + VIEW PLANS.
- Transition: persist → invalidate mode shell → remount OS. **No logout.**
- a11y: announces “Coach mode selected”.
- Offline: allow switch only if capability already cached; never invent Coach access.

Component: `ActiveExperienceSwitcher` (Android design-ui).
