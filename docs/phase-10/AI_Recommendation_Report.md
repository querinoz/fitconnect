# AI Recommendation Report

Structured `AiRecommendation`: reason, evidence, expectedBenefit, potentialRisk, alternative, confidence, overrideable=true.

Kinds: training adjustment, recovery, session prep, program modification, coach contact, education, rest, monitoring.
Human override via `ActionDecision` (accept/dismiss/ask why/ask coach/modify/reject/ignore).
Accept does **not** auto-apply plan mutations.
