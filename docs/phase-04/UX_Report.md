# Phase 04 — UX Report

## Product framing

Athlete OS is organized around **performance improvement loops**, not KPI dashboards:

1. **Sense** — readiness / recovery / HRV / sleep  
2. **Decide** — training + recovery recommendations + AI summary  
3. **Act** — today’s session, tasks, programs  
4. **Connect** — coach message, discover coaches  
5. **Reflect** — history, achievements, body metrics  

## Identity

Elite OS tokens (Voltline / Connect / floor) via Design System 2.0. Glass/person/metric card variants create hierarchy without generic “admin dashboard” chrome.
