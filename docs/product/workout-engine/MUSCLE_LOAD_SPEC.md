# Muscle Load — Specification

**Version:** 0.1 (planned P3)

## Input

Completed working sets + exercise muscle mapping.

## Output

Effective volume per muscle group for period (7d / 30d / 90d / all).

## Weighting

| Role | Factor |
|------|--------|
| Primary muscle | 1.0 |
| Secondary muscle | 0.5 |

Volume proxy: `sets × reps × (weight or bodyweight factor)` — documented approximation, not EMG truth.

## UI

FitConnect muscle map (front/back) — **original assets**, no copyrighted anatomy meshes.
